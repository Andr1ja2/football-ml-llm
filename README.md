# Tool-Aware Football Betting Assistant (v1.2)

This project is an educational football betting analysis system that combines:

-   statistical models (1X2, BTTS, Over/Under)
-   deterministic combo selection
-   live bookmaker odds
-   a local LLM (Mistral via Ollama) used strictly for explanation

The system uses machine learning models to estimate football match outcome probabilities and identify potential value bets based on bookmaker odds.

The LLM **does not make predictions**. It only explains tickets generated by deterministic code.

This project was created for **educational purposes and personal experimentation**.

It is **NOT intended to be a production betting system**, and it **does NOT guarantee profit**.

The models and analyses are simplified and are used primarily to
explore:

-   machine learning
-   probabilistic modelling
-   deterministic AI pipelines

------------------------------------------------------------------------

# Features

### Machine Learning Models

All betting logic is deterministic Python code, the LLM **only explains results**.

The system trains models for three football betting markets:

-   **1X2** (home win / draw / away win)
-   **BTTS** (both teams to score)
-   **Over/Under 2.5 goals**

Models use historical match data and engineered features such as:

-   team form
-   goals scored and conceded
-   team strength metrics
-   bookmaker implied probabilities

------------------------------------------------------------------------

### Betting Engine

The combo engine:

-   detects value bets
-   calculates expected value
-   generates multi-leg accumulator tickets
-   avoids duplicate matches in the same ticket
-   respects a maximum ticket size

------------------------------------------------------------------------

### Live Odds Integration

The system retrieves upcoming match odds from **TheOddsAPI** and applies the ML models to generate predictions for real matches.

This allows the engine to generate tickets based on actual upcoming games.

------------------------------------------------------------------------

### LLM Integration

A local LLM (Mistral via Ollama) is used for:

-   explaining generated tickets
-   summarizing risk levels
-   interpreting the model output

All predictions come from the ML models.

------------------------------------------------------------------------

# Requirements

Recommended environment:

-   Linux
-   Python **3.10+**
-   Ollama
-   a local LLM model (e.g. `mistral`)

------------------------------------------------------------------------

# Installation

Clone the repository:

git clone https://github.com/Andr1ja2/football-ml-llm.git\
cd football-ml-llm

Create a virtual environment:

python3 -m venv .venv\
source .venv/bin/activate

Install dependencies:

pip install -r requirements.txt

------------------------------------------------------------------------

# Environment Variables

Create a `.env` file in the project root.

ODDS_API_KEY=your_api_key_here

You can obtain an API key from:

https://the-odds-api.com

------------------------------------------------------------------------

# Database Setup

Initialize the database:

python src/init_db.py

Download historical football data:

python src/data_downloader.py

Ingest the data into the database:

python src/ingest.py

------------------------------------------------------------------------

# Training the Models

Train the prediction models:

python src/train_1x2.py\
python src/train_btts.py\
python src/train_ou25.py

Trained models will be saved to:

data/processed/

------------------------------------------------------------------------

# Running the Chat Assistant

Start the system:

python src/chat_cli.py

Example interactions:

generate a ticket\
generate a 4 leg ticket\
add one more\
make it risky

The assistant will:

1.  fetch live odds
2.  run ML predictions
3.  detect value bets
4.  build ticket combinations
5.  explain the ticket
